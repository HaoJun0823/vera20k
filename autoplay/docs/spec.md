# Auto play 效果规格

来源：`G:/Documents/autoplay-v2.txt`（许愿草稿）+ 2026-11-02 的答复。
这是验收的唯一依据：每条需求有一个可观测判据，历史问题每条一个永久计数。
实现方式不在本文档里。

## 1. 目标与阶梯

最终目标：**Death.mmx，1 对 7，冷酷，赢。**

分级验收，逐级推进，前一级不稳不进入下一级：

| 级别 | 判据 |
|---|---|
| G1 | 1v1 冷酷，8 个种子里赢 ≥ 6 |
| G2 | 1v3 冷酷，8 个种子里赢 ≥ 4 |
| G3 | 1v5 冷酷，8 个种子里赢 ≥ 2 |
| G4 | 1v7 冷酷，8 个种子里赢 ≥ 1，且不速崩（≥ 20 分钟）。七个冷酷同队，一起打我们 |

其余三张图：Barrel.mmx 日常回归（不退步）；xeb1.map 破墙（军队必须过墙）；
xtsunami.map 跨海（单位必须到达非起始岛）。
回放：同一 seed、同一命令流必须复现同一结果。

## 2. 冲突时的优先级

生存 > 经济 > 科技 > 扩张 > 骚扰/进攻。

例外：**围墙与基地布局是抢占式的**。一旦布局任务开始，其他单位必须让路
（移动到不影响放置的格子）；布局的优先级低于生存，高于其余一切。
不让路的单位由布局任务自己挪开，不允许"等它自己走"。

## 2.5 合法性约束

强度目标：在原版规则内，不作弊、不犯规、不卡 BUG，做到最强。

| 必须 | 不许 |
|---|---|
| 命令走玩家同一条入口 | 直接写仿真状态 |
| 使用 L0 静态地图信息（人类看地图就知道） | 使用未探索区域的实时敌情 |
| 正常点击频率内的操作 | 靠命令洪水让单位获得不存在的冷却（H5） |
| 按规则放置建筑 | 穿墙/叠放/无效地形放置 |
| 送掉自己人时计入代价 | 依靠引擎缺陷获得收益 |

"最强"是持续目标，不是一次性门槛：G1–G4 是闸门，过了之后继续提升，不以"能赢"为止。

## 3. 知识分层

| 层 | 内容 | 来源 |
|---|---|---|
| L0 静态地图 | 地形、矿脉、中立建筑、出生点 | 开局公开——玩家看地图就知道 |
| L1 已探索 | 曾经看到的敌方单位与建筑 | 记忆，随时间衰减 |
| L2 实时视野 | 当前可见的敌方单位 | 真实视野 |

禁止：用 L0 冒充 L2（例如"我知道那里有三辆坦克"）。L0 只描述地图上不变的东西。

## 6. 非目标

- 多人模式（含队友协同）。
- 自博弈。
- 20k 单位规模下的 BOT 性能；标准对局 1v7 即上限。
- 完美微操；判据是"不犯明显错误"，不是"打得像职业选手"。
- 每个 Ares/Phobos 能力的手写判断：能力效果在 sim 里，BOT 只读数据决定何时用。

## 7. 边界条件

- 开关：全局 / 生产 / 战斗 / 能力，全局是三者一起；单按切单个。
- 不控制不可控单位（如投放伞兵的运输机）。
- 每局状态独立。
- 控制权离线（battle control offline）时停止。
- 编队内的单位不托管。
