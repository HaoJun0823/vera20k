**日期**：2026-11-09

## 一句话结论

**v2 的稳定来自「少做事」，不是「做对了」。** 它把基础建造和守家做扎实了，
所以能玩、不崩；但进攻、绕路、侦察、驻扎、开分基地这些一加就崩，于是全被回退，
最后停在「军队守家、不主动打」的窄平衡上。六种子 24000 tick 的实测里，
**敌方建筑拆除数为 0**。这解释了用户说的「v2 可玩、比 v1 稳，但比 v1 弱」。

## v2 从没做过（无参考，需从零实现）

围墙、运输（海/空）、驻扎、超武、箱子、防御塔摆放、开分基地、占领、渗透、
中立建筑、微操（风筝/躲弹/分弹/卡射程）、跨阵营生产、切换主生产工厂、
出售建筑、回收厂/维修厂/克隆缸。

`status.md` Known gaps 与 `features.md` 批次清单均确认。许愿书里最花哨、
也是让 v1 显得强的部分，v2 一片空白。

## 测量规矩（血换来的，必须沿用）

1. 记录必须带 ticks / speed / difficulty，否则不同长度的读数无可比性。
2. **1v7 只当「有没有整体崩」的报警器，不作验收尺**（同代码三种子读出 87/82/16）。
3. 一次只改一处、一次测量；改善一个读数却在另一张图丢种子，就回退。
4. 验收用固定地图 + 固定种子横向对比版本自身，不以「打赢零售 AI」为准。
